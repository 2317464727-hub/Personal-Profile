# 个人平台

## 2026-11-03 更新：实习经历分条整理

实习记录读取已保存简历中的经历，并与原有公司工作记录、双周总结合并展示。用户整理的展示文案保存在个人资料的 `internshipRecords` 中，按公司名关联，包含原始来源 `sourceText`、简介、工作模块和整体成果；沿用现有资料同步与备份。个人资料表单保存时保留此字段。

没有各项工作的确切日期时，左栏使用“工作模块 01–05”，只保留简历已有的任职起止时间。整理版仅在来源原文匹配时展示；简历经历有实质修改后，自动显示新原文，避免继续展示过期整理内容。此整理不改写简历本身。

## 2026-11-03 更新：统一界面样式

桌面宽度超过 1180px 时使用左侧导航，较窄窗口使用可横向滚动的顶部导航。周历、AI 工作台、任务、个人中心、实习记录与工作区统一为蓝灰色系，支持夜间模式；新增样式只用于屏幕，不调整简历打印与 PDF 版式。

样式按 `ui-shell.css`、`ui-calendar.css`、`ui-agent.css`、`ui-pages.css` 分开维护，由本机服务白名单提供。已有资料、工具权限和附件位置沿用原逻辑；保存的侧栏宽度会受当前窗口限制，避免挤掉主内容。

## 2026-11-03 更新：资料保存、授权任务与草稿审核

- **资料保存与备份**：打开本机页面后，个人资料、周历文字、简历及照片、简历草稿、AI 对话和关键词同步到 `.personal-state.sqlite3`。首次打开会迁移浏览器资料；已有两个不同版本时，在任务页选择使用哪份，系统不会自动覆盖。保存失败仍保留浏览器内容，并显示重试入口。8766、8767 使用同一服务资料库，切换页面或浏览器前请确认显示已保存。
- **备份范围**：任务页底部“资料保存与备份”可导出和确认恢复。恢复前自动保留服务端版本，也可下载恢复前版本。这个 JSON 不含周历/画布附件文件、定时任务计划、访问权限和密钥；请另外保留附件。它不是整个项目的完整备份。
- **定时资料授权**：新建 AI 分析时可选周历、当前简历正文及最多三个指定桌面文本/Word 文件，并单独勾选允许该任务每次运行发送这些资料。授权持续至编辑撤回或取消；不会继承普通聊天权限。运行时读取已同步的资料，简历结构化姓名/联系方式/照片字段不传给模型。正文和文件中自行包含的个人信息仍属于所选内容。
- **多轮执行和来源**：任务按问题检索、观察工具结果并继续，最多五轮，重复查询会停止。无私密资料授权的任务可以搜索公开网页；授权本机资料的任务只使用对应本机工具。来源、结果和草稿保存在任务中。服务必须运行，页面无需保持打开；通知弹窗仍需要页面打开。
- **确认应用与撤销**：有草稿时在任务结果点击“预览草稿”，检查修改前后再确认写入。简历草稿原地替换指定的导入栏目，既有独立补充项保留；文件草稿是文本/Word 单处精确替换。系统保存原文/文件备份，支持撤销。起草或预览后内容变化时拒绝覆盖；应用后再次编辑会阻止自动撤销。历史运行的草稿和撤销入口在“以往草稿与撤销记录”中。

以上是当前行为；下文的早期版本介绍保留历史背景，如有不同以本节为准。

用 Python 3.10+ 运行 `ai_server.py`，然后打开 `http://127.0.0.1:8766/`。API 密钥放在 `.env` 或 `SUB2API_API_KEY` 环境变量中；模型、推理强度和代理附加请求头分别由 `SUB2API_MODEL`、`SUB2API_REASONING_EFFORT` 和 `SUB2API_ACTOR_AUTHORIZATION` 配置。本机当前使用 `gpt-6-sol` 和 `high`。

“个人中心”右上角的“编辑个人中心”可修改姓名、岗位、公司、标题、介绍、工作重点及基本资料，也可增删工作重点。内容保存在当前浏览器，刷新后保留；旧版已填写的学校、电话、邮箱和城市会继续显示。“最近记录”从周历自动读取，在周历中修改。已上传的简历正文独立保存，不会被个人中心覆盖。

AI 页上半部分可显示网站，网址栏可输入任意 HTTP/HTTPS 地址或域名。Codex 中使用 `/skills` 选择“浏览器”，或直接使用 `$open-site-window`；技能会把网址交给本机平台，已打开的平台标签页会自动显示预览。网页预览不会自动把网站内容发送给上游模型服务。部分网站会拒绝被其他页面内嵌，这由网站自身控制。

普通 AI 对话下方可选择“浏览器权限”：初次打开默认关闭；“读取网页”允许模型打开、读取和返回 AI 专用 Edge 浏览器；“操作网页”还允许点击和填写普通输入框。选中的权限会保存在当前浏览器，发送消息或刷新页面后继续生效，直到手动关闭。若上方已有网页预览，第一次授权提问会把同一网址打开到专用浏览器；之后的连续提问保留专用浏览器的导航状态，直到预览网址再次变化。浏览器模式不附带桌面快照、周历正文、编辑区内容或文件工具；模型调用网页读取工具时，读取到的网页内容会发送给上游模型服务。它不能读取用户原有的 Codex 浏览器标签页。

“本机资料”初次打开默认全部关闭。只发送当前输入的问题，以及相同权限下最近的新对话；旧版对话不进入模型上下文。勾选“周历记录”后，从当前浏览器保存的全部周历按问题检索，发送最多 24 条相关记录及 ID，不再固定只取最近 16 条；无明显命中时回退到最近记录。勾选“编辑区与附件”才发送右侧备注、文档预览和图片；勾选“本机文件”后，本机服务会在已允许目录中按问题检索最多 5 个文本片段并发送给模型，模型仍可按需调用只读文件工具。“项目操作”只检索当前仓库。文件名、路径及命中的片段会作为来源显示在回答旁；敏感文件按原有规则排除。桌面文件名快照不再自动生成或发送。浏览器权限与本机资料权限互斥；选中的权限会保存在当前浏览器，持续到手动关闭，开启浏览器权限会清除本机资料选择。平台内的本机双周总结和按模板整理仍在本机完成。

“项目操作”只允许 Agent 在当前 `whq agnnt` 仓库内读取、精确替换或新建普通 UTF-8 文本源文件，并运行 `repo_node`、`personal_python`、`personal_browser` 三种预设测试。界面会显示文件差异和测试输出。选中后持续生效，手动取消才会关闭。它默认不开放桌面或其他工作目录；如需读取这些目录，要另外选择“本机文件”。项目工具不支持删除、重命名或任意命令。预设测试会执行当前仓库中的测试代码，因此只在信任当前项目代码时启用。读取的项目内容和测试输出会发给上游模型服务；未启用时不会提供项目操作工具。

AI 页右上角“桌面文件”可以指定一个桌面内的文件进行修改。选择文件后可先查看本机内容，再填写修改参数并预览差异；只有点击“确认写入并备份”才保存原文件备份并写入，历史记录可撤销。当前支持 UTF-8 文本和 Word 的单处原文替换、图片尺寸调整、PDF 指定页旋转；不支持删除、发布或任意命令。文本和 Word 可输入修改要求，点击“本次允许发送所选文件给模型并起草”，本次才会把该文件文字发送给已配置模型；模型只返回一处替换草稿，不负责确认写入。手动操作和查看文件不会把内容发送给模型。预览 20 分钟后过期；如果文件在预览或写入后被其他程序改动，写入或撤销会被拒绝。“项目操作”权限不会因此获得桌面写入能力。

“任务”页可创建一次、每天或每周的提醒与 AI 分析。按北京时间运行；提醒进入“待你决定”，可标记已处理或延后一小时。AI 分析只使用任务文本和公开网页搜索，结果、失败原因或需要你决定的事项都留在任务页；待决定项可带到 AI 输入框由你补充处理，失败后可手动重试。支持编辑、立即运行、暂停、恢复和取消计划。任务与运行进度保存在本机 `personal/.agent-tasks.sqlite3`，服务重启后仍在；服务停止期间不会运行，到期任务会在服务恢复后执行，运行中断的只读任务在约四分钟租约过期后重新执行。两个本机端口共享数据库，避免重复领取同一次任务。任务数据库已从文件检索中排除。AI 对话每完成一轮工具调用也会保存检查点；断线或重启后，“任务”页显示待继续的对话，继续时仍需恢复原来的访问权限。

个人平台的 AI 输入框支持 `/浏览器`、`/浏览器 打开网页` 或 `/浏览器 https://example.com/`；旧的 `/打开这个` 仍可用。输入 `/` 会显示“浏览器”技能。可在一句话里放多个网址，明确写“第二个”或站点名称会自动选中；无法判断时会显示候选列表。最近打开的网站可按域名再次找到。

“实习记录”页可启用本机双周总结，并设置首次生成日期和时间；之后每隔 14 天生成一次。总结依据周历里的工作记录在本机整理，不调用外部 AI。服务必须持续运行；关闭服务后不会定时执行，重新启动时会处理到期任务。从 `file://` 页面切换到服务版时，两边的浏览器存储不共享，可先在周历导出 JSON，再到服务版“实习记录”导入。

“简历”页可上传 PDF、DOCX 或 TXT。服务只在本机内存中提取文字并按栏目分类，不保存原文件，也不会发送给外部 AI；用户核对预览后，识别结果才保存在当前浏览器。扫描版 PDF 没有可提取的文字时会提示转换文件。

简历导入按完整条目核对公司名、岗位和任职时间：即使原文把公司写在“项目经历”下，明确的任职条目也会整段移到“实习 / 工作经历”，并在识别预览中说明调整。正文里提到客户公司不会触发搬移；缺少岗位、无法确定的条目保留原分类并提示核对。支持日期在标题前、标题后或单独一行，以及 DOCX 表格内分行的标题。技术与方法在主栏按主题分组展示，接合 PDF 换行，保留“了解 / 熟悉”等原文表述；分组不改写已保存的简历。

简历右上角“导出单页 PDF”直接下载一张 A4 简历，无需使用系统打印机。当前页面上展示的简历内容通过 `/api/resume/pdf` 交给本机 ReportLab 排版，文字可搜索；不调用模型、不保存正文和 PDF 到服务端。导出采用清晰的中文无衬线字体、加粗的章节与条目标题，以及仅包住内容的浅色右栏；日期与岗位信息根据和标题的实际合计宽度决定是否右对齐，放不下才另起一行，列表换行采用悬挂缩进。内容较多时会自动收紧条目间距和页边距，细调栏宽，并按最终行距选择能装下一页的正文大小；正文上限 9.2 pt，下限 6.8 pt。个人优势放在最底部，荣誉奖项在右栏。内容超出可读单页容量时会提示精简，保留原内容供编辑，不会裁掉末尾或生成额外空白页。依赖为 ReportLab 和 Windows 微软雅黑（缺少时使用等线），平台启动脚本使用的内置 Python 已包含所需组件。

已配置 Windows 登录自启动：启动项会运行 `start_personal_platform.ps1`，先检查 8766 端口，再启动 `ai_server.py` 并打开本机页面。若要手动启动，可在 PowerShell 运行该脚本。

个人平台 AI 输入框输入 `/` 可选择“简历整理”，输入 `/简历` 也能直接打开 AI 区上半屏的审核区。这里会读取近期尚未加入简历的周历记录，按公司、项目和工作要点生成本机草稿；可调整日期范围、编辑内容并确认写入。点“手动添加完整经历”可录入一整段经历和技能。AI 写入的内容会作为独立补充项保存，在简历页逐条编辑或移除，不改动原始简历正文；旧版已合并到正文的 AI 段落会在本机迁移为可移除补充项。当前整理使用本机规则，不调用上游模型服务，不会推断未记录的结果。平台必须从本机 HTTP 地址打开才能使用此功能。

在 AI 输入框要求“根据近 30 天工作优化第一份简历”时，会先显示本次分析授权。授权后才发送当前保存的简历正文和所选周历记录给已配置模型，不发送姓名、联系方式和照片字段。模型给出改进建议和一段完整的实习经历草稿；公司、岗位和任职时间须沿用原简历，草稿要点须有周历来源。草稿默认不勾选，编辑和确认写入前不会修改简历。分析结果及编辑中的草稿保存在当前地址的浏览器存储；同一标签刷新或切页后恢复原页面与审核面板，主动关闭后可点“继续简历草稿”恢复。不同端口的存储互不共享。可点“重新分析”重新授权并生成。写入的是可独立移除的补充项，原始简历正文保留。

在 AI 输入框直接说“帮我写简历”“给我写一份简历”“按现在的模板生成简历”“把我这几天做的事写进简历”等请求，会打开 AI 上半屏的完整简历预览。预览与 PDF 导出共用栏目数据：实习、项目在主栏，教育、技能、证书、奖项在右栏，个人优势在底部。现有简历与近期新增工作共同展示，同公司和同项目的补充按标题归入原条目；没有新增记录时仍能预览整份简历。项目草稿包含名称、记录月份和工作要点，不推断任职日期或未验证成果。可切换“编辑新增内容”，核对后点击“确认写入简历”；AI 补充仍能逐条移除。整理继续在本机完成，不调用上游模型服务。普通的写作方法提问和“不要写简历”不会启动生成。

AI 会在一次已授权的任务中根据工具结果继续判断和推进。输入框下方的“连续推进”默认开启，可随时关闭；开启时每段最多调用 5 轮工具，到达上限后自动续做，单次提交最多连续执行 3 段。相同工具及相同参数连续调用 3 轮后会停止重复调用。达到连续执行上限、关闭开关或刷新页面后，仍可用“继续任务”手动恢复；恢复时必须保持原来的浏览器和本机资料权限。任务需要用户决定或缺少授权时，AI 应说明阻碍并停止。服务会在每轮工具调用结束后保存结果和下一轮上下文；检查点保存在 `personal/.agent-checkpoints.json`（已忽略 Git，文件工具不可读取），最多保留 8 条、每条 7 天；它可能包含已授权工具读取的内容，放弃或任务完成后会删除。

AI 页的“记忆”可查看短期对话和长期关键词：相同访问权限下最近 12 次对话参与下一次提问，浏览器最多保存 60 次对话。新提问提取的关键词按访问权限保存，同一权限下最多 16 个关键词可作为未核实的主题线索发送给上游模型服务；不会把旧版无权限标记的关键词发送出去。关键词不包含周历正文、文件内容或简历正文，可在“记忆”中清除；本机直接回答的简历和工作区内容仍不会进入模型对话。

在 AI 页询问“这个项目的简历页”时，平台会直接从当前浏览器保存的简历读取并回答栏目内容，不调用文件搜索或上游模型服务；未保存上传版本时会明确说明当前显示的是平台原版简历。需要模型分析的其他问题仍走原来的 Agent 流程，保存的简历正文不会自动发送给模型。

明确询问“第一份简历里有没有某项内容”时，本机按问题在所选简历栏目中查找，结果标明 `[简历:栏目]`；未指定第一份或第二份时仍先询问选择。此类本机查看不会将简历正文发送给模型。
